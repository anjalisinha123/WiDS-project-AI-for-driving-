## WiDS-Project-AI-for-Self-Driving-Car-Build-a-Traffic-Sign-Classifier-Report
# Week -1

I focused on learning the fundamentals of the Python programming language to establish a solid base. This involved understanding Python syntax and implementing essential programming concepts such as loops, functions, and logical control structures. I also practiced solving algorithmic problems to strengthen my problem-solving skills.

# Week -2

During this week, I concentrated on Data Analysis with an emphasis on Exploratory Data Analysis (EDA). I used the Pandas and NumPy libraries to load, process, and analyze datasets efficiently. My work included data cleaning and performing various operations to ensure the data was well-prepared for further modeling.

# Week -3

I moved on to Machine Learning by studying the basics of classical ML algorithms. This included both the theoretical understanding and practical implementation of Linear Regression and Logistic Regression. I learned how these models help identify relationships between variables and perform classification tasks.

# Week -4

I progressed to Deep Learning concepts, focusing on Neural Networks. I built Artificial Neural Networks (ANNs) and Convolutional Neural Networks (CNNs) using TensorFlow and Keras. These models were applied to image classification tasks, particularly using the MNIST dataset, to analyze model architecture and performance.

# Week -5

I have applied my cumulative knowledge to a capstone project focused on Autonomous Driving systems. I developed a Traffic Sign Classifier using the German Traffic Sign Recognition Benchmark (GTSRB) dataset. My work involved constructing a robust Convolutional Neural Network (CNN) with advanced layers like Dropout to prevent overfitting, optimizing the model to recognize 43 distinct classes of traffic signs with high accuracy.
